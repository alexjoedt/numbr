# Security Policy

## Supported Versions

numbr is `0.x` alpha software. Only the latest released version is supported; there are
no backported security fixes to older releases.

| Version | Supported |
|---------|-----------|
| latest `0.1.x` | yes |
| older | no |

## Reporting a Vulnerability

Please do not open a public issue for security vulnerabilities. Use GitHub's private
vulnerability reporting instead: go to the [Security tab](https://github.com/alexjoedt/numbr/security)
and click **Report a vulnerability**.

This is a single-maintainer hobby project. Response time is best effort, typically
within two weeks. You will get an acknowledgement and, if the report is valid, a fix or
a plan for one before any public disclosure.
